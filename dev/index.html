FIIBCICorpus Documentation

FIIBCICorpus is the data loader of the Eegle ecosystem for the FII BCI Corpus.

It downloads the databases of the corpus in NY format. The NY files are then read and processed with Eegle, which depends on FIIBCICorpus and re-exports it.

🧩 Requirements

Julia: version ≥ 1.13

⚙️ Installation

Execute the following commands in Julia's REPL:

]add FIIBCICorpus

then hit the 'back' keyboard key to exit the REPL package manager mode.

—͟͟͞͞★ Quick Start

using FIIBCICorpus

downloadDB() # run the GUI to download the corpus in the homedir

Read the next page of this documentation for general informations.
