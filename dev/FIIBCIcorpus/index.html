FIIBCIcorpus

Is the data loader of the Eegle ecosystem. It is organized as a collection of modules, which are all re-exported. Thus, if you state

using FIIBCIcorpus

you have access to all functions exported by all FIIBCIcorpus modules. Since Eegle re-exports FIIBCIcorpus, using Eegle gives access to them as well.
